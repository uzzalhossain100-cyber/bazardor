# বাজারদর (BazarDor)

> পণ্যের নাম লিখুন, আজকের দাম জানুন।

বাংলাদেশের চারটি প্রধান অনলাইন গ্রোসারি সাইট (স্বপ্ন, চালডাল, অ্যাগোরা, মীনা বাজার) এবং দুটি ঔষধ সাইট (আরোগা, মেডেক্স) থেকে পণ্যের দাম এনে এক জায়গায় তুলনা করে দেখায়।

## প্রযুক্তি
- সামনে: একটি মাত্র এইচটিএমএল ফাইল (`public/index.html`) — কোনো ফ্রেমওয়ার্ক নেই
- পেছনে: `/api` ফোল্ডারের সার্ভারলেস ফাংশন (Node 18+, কোনো প্যাকেজ লাগে না)
- হোস্টিং: **Vercel** (ফ্রি প্ল্যান যথেষ্ট)

## এপিআই এন্ডপয়েন্ট
| এন্ডপয়েন্ট | কাজ |
|---|---|
| `GET /api/search?q=চাল` | চার গ্রোসারি সাইট থেকে দাম |
| `GET /api/med?q=napa` | আরোগা + মেডেক্স ঔষধের দাম |
| `GET /api/health` | সার্ভার ঠিক আছে কি না |
| `GET /api/qr` | অ্যাপ ডাউনলোড লিঙ্কের ডাইনামিক QR কোড |

## লোকাল টেস্ট
```bash
node server.js   # মূল ডেভ সার্ভার (বিকল্প)
```
অথবা সরাসরি `vercel dev` চালাতে পারেন।

## Vercel-এ ডিপ্লয় (৩ ধাপ)
1. এই রিপোজিটরি GitHub-এ পুশ করুন
2. [vercel.com](https://vercel.com) → **Add New → Project** → রিপোজিটরি **Import** করুন
3. **Deploy** চাপুন — কয়েক সেকেন্ডেই লাইভ ইউআরএল পাবেন (যেমন `https://bajardor.vercel.app`)

কোনো বিল্ড সেটিং দিতে হবে না; এনভায়রনমেন্ট ভেরিয়েবল `FETCH_TIMEOUT=6000` আগে থেকেই `vercel.json`-এ সেট করা আছে।
